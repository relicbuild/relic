`relic` is the command-line client. The same binary also runs the server.
The client talks to a server through the [Relic API](/docs/api/relic-api).

You keep repositories, users, groups, permissions, LDAP settings and security
policies in YAML files, and apply them the way you would with `kubectl apply`.

Each command names what it acts on first, then what it does (`relic artifact cp`,
`relic auth login`):

| Group | Does | Page |
| --- | --- | --- |
| `relic server` | runs, installs and inspects the server on this machine: `start`, `worker`, `migrate`, `setup`, `stop`, `status`, `config`, `uninstall`, `database` | [Machine setup](/docs/cli/setup), [Database](/docs/cli/database) |
| `relic auth` | `login`, `logout`, `status`, `context`, `token` | [Sign in and contexts](/docs/cli/sign-in), [Server, API and tokens](/docs/cli/platform) |
| `relic artifact` | `upload`, `download`, `cp`, `mv`, `rm`, `search`, `props`, `lfs` | [Artifacts](/docs/cli/files) |

## Install

The install script downloads the latest release for Linux or macOS (amd64 or
arm64). It checks the release's SHA-256 sum and puts `relic` in `~/.local/bin`:

```bash
curl -fsSL https://relic.build/install.sh | sh
```

Set `RELIC_VERSION` to install a specific release, and `RELIC_INSTALL_DIR` to
install into another directory:

```bash
curl -fsSL https://relic.build/install.sh | sudo env RELIC_VERSION=v1.2.3 RELIC_INSTALL_DIR=/usr/local/bin sh
```

A Relic server also serves the script at `/install.sh`.

Every release on GitHub (github.com/relicbuild/relic/releases) contains:

- archives for Linux and macOS (amd64 and arm64) and Windows (amd64, a zip), with
  the web UI built in
- `relic_<tag>_checksums.txt`, which lists the SHA-256 sums of the archives
- a cosign signature of that file (`relic_<tag>_checksums.txt.sigstore.json`)
- an SBOM for each archive

To install by hand on Linux or macOS, first set the release you want and your
platform (`linux_amd64`, `linux_arm64`, `darwin_amd64` or `darwin_arm64`):

```bash
v=v1.2.3 p=linux_amd64
```

Download the archive and the checksum files:

```bash
gh release download "$v" --repo relicbuild/relic -p "relic_${v}_${p}.tar.gz" -p "relic_${v}_checksums.txt*"
```

Optionally, verify the signature of the checksum file:

```bash
cosign verify-blob "relic_${v}_checksums.txt" --bundle "relic_${v}_checksums.txt.sigstore.json" --certificate-oidc-issuer https://token.actions.githubusercontent.com --certificate-identity-regexp '^https://github.com/relicbuild/relic/'
```

Check the archive against its SHA-256 sum:

```bash
sha256sum -c --ignore-missing "relic_${v}_checksums.txt"
```

Unpack the archive and install `relic` in `~/.local/bin`:

```bash
tar -xzf "relic_${v}_${p}.tar.gz" && install "relic_${v}_${p}/relic" ~/.local/bin/
```

Print the installed version:

```bash
relic --version
```

The archive does not include the scanners (syft, grype, gitleaks, trivy). The
Relic image has them. A server without them runs with scanning turned off.

The Relic image also contains the binary at `/relic`. You can copy it out of the
image, or build it from source. To copy it out, create a container from the
image without starting it:

```bash
docker create --name relic-cli <relic-image>
```

Copy the binary out of it:

```bash
docker cp relic-cli:/relic ./relic
```

Remove the container:

```bash
docker rm relic-cli
```

To build it from source, run this in a checkout of the repository:

```bash
go build -o ~/bin/relic ./cmd/relic
```

Next, run `relic server setup`. It adds shell completion and runs the server
as a systemd service. See [Machine setup](/docs/cli/setup).
