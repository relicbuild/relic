---
title: Scan reports and VEX
description: Show a stored file's scan, list operational risks, and exchange SBOMs and VEX documents.
---

## A stored file's scan

Show what Relic Scan found in a stored file:

```bash
relic security report libs-local/org/app/1.0/app.jar
```

With `--fail-on`, exit with status 1 when a finding or risk is that severe or
worse, or while the scan is queued or has failed:

```bash
relic security report charts/demo-0.1.0.tgz --fail-on high
```

For an image tag folder, the report shows the tag manifest's scan:

```bash
relic security report docker-local/team/app/1.4.0 -o json
```

## Operational risks

List end-of-life, deprecated or unmaintained components:

```bash
relic security risks
```

List one kind in one repository:

```bash
relic security risks --kind end_of_life --repository libs-local -o json
```

## SBOMs

Write an item's SBOM as CycloneDX, SPDX or Syft JSON:

```bash
relic security sbom export libs-local/app/app-1.4.0.jar --format cyclonedx > app.cdx.json
```

Replace an item's SBOM with your own:

```bash
relic security sbom import libs-local/app/app-1.4.0.jar build/bom.json
```

For an image, give its folder (`docker-local/web/1.2`).

## VEX

Export the ignore rules as OpenVEX `not_affected` statements:

```bash
relic security vex export > relic.vex.json
```

Export CycloneDX, adding Go vulnerabilities no code calls:

```bash
relic security vex export --format cyclonedx --unreachable --file relic.cdx.json
```

Import an OpenVEX or CycloneDX document's `not_affected` and `fixed`
(`resolved`) statements as ignore rules (administrators):

```bash
relic security vex import vendor.vex.json
```

## The vulnerability database

Import the vulnerability database offline:

```bash
relic security database import grype-db.tar.zst
```

Show its state:

```bash
relic security database status
```

## End-of-life data

Import endoflife.date data offline:

```bash
relic security end-of-life import eol.json
```

Show its source and age:

```bash
relic security end-of-life status
```
