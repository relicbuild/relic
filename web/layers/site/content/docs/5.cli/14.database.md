---
title: Database
description: Copy a Relic database between PostgreSQL and SQLite, and back up a SQLite database.
---

These commands open the database directly, without a server.

Copy every table into an empty database, PostgreSQL to SQLite or the other way,
in one transaction, then compare row counts. Stop Relic first:

```bash
relic server database copy --from "$RELIC_DATABASE_URL" --to sqlite:///var/lib/relic/data/relic.db
```

Write a snapshot of the SQLite database in `RELIC_DATABASE_URL` while Relic
runs:

```bash
relic server database backup /backups/relic-$(date +%F).db
```

Restore it by stopping Relic and putting the file in the database's place.
Back up PostgreSQL with `pg_dump`. See
[Limits and backups](/docs/installation/single-binary/operations).
