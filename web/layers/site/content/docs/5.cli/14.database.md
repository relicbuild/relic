---
title: Database
description: relic server database copy and relic server database backup work on a Relic database directly.
---

These commands open the database directly, as `relic server migrate` does. They
do not talk to a server.

| Command | Does |
| --- | --- |
| `relic server database copy --from <url> --to <url>` | Copies every table into an empty database, from PostgreSQL to SQLite or the other way, in one transaction. Then checks the row counts. Stop Relic first. |
| `relic server database backup <file>` | Writes a consistent snapshot of a SQLite database while Relic runs. Takes the database from `RELIC_DATABASE_URL`, or from `--database-url`. |

Copy the current database to a SQLite file:

```bash
relic server database copy --from "$RELIC_DATABASE_URL" --to sqlite:///var/lib/relic/data/relic.db
```

Back up a SQLite database to a file named after today's date:

```bash
relic server database backup /backups/relic-$(date +%F).db
```

Back up a PostgreSQL database with `pg_dump`. To restore or move an
installation, see [Limits and backups](/docs/installation/single-binary/operations).
