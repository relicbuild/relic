---
title: apply, diff and delete
description: Create, update and delete resources from YAML files, and export them with relic get.
---

Show what `apply` would change, as a unified diff:

```bash
relic diff -f relic.yaml
```

Create the resources that are missing and update the ones that differ:

```bash
relic apply -f relic.yaml
```

Delete the resources in the file, in reverse order:

```bash
relic delete -f relic.yaml
```

- `apply` works through the file in order. For each resource it prints
  `created`, `configured` or `unchanged`. Applying the same file twice changes
  nothing.
- A spec sets only the top-level fields it names. Fields it leaves out keep
  their current values on the server. This lets a file manage a repository's
  description without knowing its other settings.
- `diff` and `apply` do not compare write-only fields, because the server never
  returns them. These are a user's password, a remote repository's password, an
  LDAP manager password, a webhook's secret, a replication's password, and an
  identity provider's OIDC client secret. To change only one of them, run
  `apply --force`.
- They do not compare output-only fields either, which the server sets and
  ignores on writes: timestamps, usage, a user's realm, and an identity
  provider's callback path and SAML certificate. No apply changes them.
- `diff --exit-code` exits with 1 when something would change. Use it in CI
  checks.
- `delete --ignore-not-found` does not fail when a resource is already gone.
- `-f -` reads standard input. You can give `-f` several times.

You can apply anything that `relic get -o yaml` prints.

List the repositories:

```bash
relic get repositories
```

Print their names alone, one per line, for a script:

```bash
relic get repositories -o name
```

Print them as one JSON array of Relic API messages, `[]` when there are none:

```bash
relic get repositories -o json
```

Print one repository as a `relic.build/v1` document:

```bash
relic get repository libs-local -o yaml
```

Save all permissions to a file:

```bash
relic get permissions -o yaml > permissions.yaml
```
