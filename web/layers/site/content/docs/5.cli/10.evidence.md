---
title: Evidence
description: Sign statements about files, store them as evidence and verify them.
---

Evidence is a signed [in-toto](https://in-toto.io) statement about a file, such
as test results, an approval or a review. Relic stores it next to the file in a
DSSE envelope. Relic refuses evidence unless one of its signatures verifies
with the trusted key its `keyid` names.

First, an administrator creates a key pair once. The key type is ed25519 by
default; `--type ecdsa|rsa` picks another. The server then trusts the public key
under the alias `ci`:

```bash
relic evidence keygen --file ci-signing --alias ci
```

In the pipeline, sign a statement about a file and store it as evidence:

```bash
relic evidence create libs-local/app/1.0/app.jar \
  --predicate tests.json --predicate-type https://relic.build/evidence/tests/v1 \
  --key ci-signing.key --alias ci
```

Show a file's evidence. Add `-o json|yaml` for structured output:

```bash
relic evidence get libs-local/app/1.0/app.jar
```

Verify a file's evidence. The command exits with status 1 unless every
envelope verifies:

```bash
relic evidence verify libs-local/app/1.0/app.jar
```

Verify against a public key file instead of the server's trusted keys:

```bash
relic evidence verify libs-local/app/1.0/app.jar --public-key ci-signing.pub
```

`relic evidence verify` downloads each envelope and checks it locally:

- It checks the signature against the `--public-key` files, or against the
  server's trusted keys.
- It checks the statement's subject against the file's current SHA-256. Evidence
  about a file that has since been replaced fails this check.
