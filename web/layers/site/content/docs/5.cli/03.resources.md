---
title: Resources
description: The relic.build/v1 YAML documents relic applies, and the Relic API message behind each kind.
---

A resource file holds one or more YAML documents, separated by `---`:

```yaml
apiVersion: relic.build/v1
kind: Repository
metadata:
  name: libs-local
spec:
  class: local            # local, remote or virtual
  format: maven
  description: Our libraries
---
apiVersion: relic.build/v1
kind: Group
metadata:
  name: developers
spec:
  description: Everyone who builds
  defaultForNewUsers: true
---
apiVersion: relic.build/v1
kind: Permission
metadata:
  name: developers-libs
spec:
  rules:
    - resource: repository
      selector: {repositories: [libs-local]}   # or sets: [all], [local], [remote]
      include: ["**"]
      grants:
        - {group: developers, actions: [read, write, annotate]}
```

Each document's `spec` is the Relic API message for its kind, written in that
message's JSON form. The protos document every field. A misspelled or unknown
field is an error, in `spec` and around it. The resource's name goes in
`metadata.name`, the only field `metadata` takes.

| Kind | Relic API message | Name field |
| --- | --- | --- |
| `Repository` | `Repository` | `name` |
| `User` | `User` | `name` |
| `Group` | `Group` | `name` |
| `Permission` | `Permission` | `name` |
| `LdapServer` | `LdapServer` | `name` |
| `LdapGroupMapping` | `LdapGroupMapping` | `name` |
| `IdentityProvider` | `IdentityProvider` | `name` (`oidc.clientSecret` is write-only) |
| `WorkloadIdentity` | `WorkloadIdentity` | `name` |
| `Policy` | `Policy` | `name` |
| `Watch` | `Watch` | `name` |
| `Replication` | `Replication` | `repository` (a standard 5-field cron `schedule`) |
| `CleanupPolicy` | `CleanupPolicy` | `name` |
| `PromotionGate` | `PromotionGate` | `name` |
| `Webhook` | `Webhook` | `name` (`secret` is write-only) |
| `Project` | `Project` | `key` (`spec.name` is the project's display name) |
