---
title: Resources
description: The relic.build/v1 YAML documents relic applies, and the Relic API message behind each kind.
---

A resource file holds YAML documents separated by `---`:

```yaml
apiVersion: relic.build/v1
kind: Repository
metadata:
  name: libs-local
spec:
  class: local            # local, remote or virtual
  format: maven
  description: Our libraries
---
apiVersion: relic.build/v1
kind: Group
metadata:
  name: developers
spec:
  description: Everyone who builds
  defaultForNewUsers: true
---
apiVersion: relic.build/v1
kind: Permission
metadata:
  name: developers-libs
spec:
  rules:
    - resource: repository
      selector: {repositories: [libs-local]}   # or sets: [all], [local], [remote]
      include: ["**"]
      grants:
        - {group: developers, actions: [read, write, annotate]}
```

Each document's `spec` is the JSON form of the Relic API message of the same
name as its kind; the protos document every field. Unknown fields are errors.
`metadata` takes only `name`.

Kinds: `Repository`, `User`, `Group`, `Permission`, `LdapServer`,
`LdapGroupMapping`, `IdentityProvider`, `WorkloadIdentity`, `Policy`, `Watch`,
`Replication`, `CleanupPolicy`, `PromotionGate`, `Webhook` and `Project`.
`metadata.name` fills the message's `name` field, except for `Replication`
(`repository`) and `Project` (`key`; `spec.name` is the display name).
