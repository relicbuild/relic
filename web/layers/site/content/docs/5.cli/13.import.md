---
title: Migrating from Artifactory
description: Copy the repositories, files, groups and permissions of a JFrog Artifactory® into Relic.
---

`relic import artifactory` copies a JFrog Artifactory® into the Relic server
you are signed in to: groups, local, remote and virtual repositories,
permission targets, and local repositories' files with their properties. It
only reads the source, through its REST API.

Preview the import:

```bash
relic import artifactory https://artifactory.example.com --user admin --password-stdin --dry-run
```

Run the import, with the password on standard input:

```bash
relic import artifactory https://artifactory.example.com --user admin --password-stdin
```

Import one repository, with an access token on standard input:

```bash
cat source.token | relic import artifactory https://artifactory.example.com --token-stdin --repository libs-release
```

- Running again resumes or picks up changes. Existing repositories, groups and
  permissions stay unless `--update`; files Relic holds with the same SHA-256
  are skipped.
- `--repository` limits repositories and files, not groups or permission
  targets. An unknown name fails the import before it copies anything.
- A virtual repository loses members that were not imported, with a note.
- Files are uploaded with the source's checksums, which Relic verifies.
- A federated repository becomes a local one, with a note. Federate it again
  with a [replication](/docs/guides/replication).
- Users are not copied. Connect LDAP or create them again.
- Remote caches are not copied; Relic fills them on demand.
