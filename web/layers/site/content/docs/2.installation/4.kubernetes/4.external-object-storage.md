---
title: External object storage
description: Run Relic from the chart against Amazon S3, Cloudflare R2, MinIO, Google Cloud Storage, Backblaze B2 or your own SeaweedFS.
---

To use your own object store, turn off the `seaweedfs` dependency and point Relic
at your store.

1. Create the two buckets, and give `temporary` a one-day expiry. The page for
   your provider shows how: [SeaweedFS](/docs/installation/storage/seaweedfs),
   [Amazon S3](/docs/installation/storage/amazon-s3), [Cloudflare R2](/docs/installation/storage/cloudflare-r2),
   [MinIO](/docs/installation/storage/minio), [Google Cloud Storage](/docs/installation/storage/google-cloud-storage),
   [Backblaze B2](/docs/installation/storage/backblaze-b2) or [another service](/docs/installation/storage/other).
2. Create the `relic` namespace:

   ```bash
   kubectl create namespace relic
   ```

   Create a Secret in it with the key pair, the password of the first `admin`
   and the encryption key:

   ```bash
   kubectl -n relic create secret generic relic \
     --from-literal=objectStorageAccessKey='<access-key>' --from-literal=objectStorageSecretKey='<secret-key>' \
     --from-literal=adminPassword='<admin-password>' \
     --from-literal=encryptionKey="$(openssl rand -base64 32)"
   ```

3. Put these settings in `values.yaml`:

   ```yaml
   seaweedfs:
     enabled: false
   existingCredentialsSecret: relic
   objectStorage:
     endpoint: https://s3.eu-central-1.amazonaws.com
     region: eu-central-1
     artifactsBucket: example-relic-artifacts
     temporaryBucket: example-relic-temporary
   ```

4. Download the chart's dependencies:

   ```bash
   helm dependency build helm/relic
   ```

   Install Relic with your values:

   ```bash
   helm install relic helm/relic -n relic -f values.yaml
   ```

If you turn off both dependencies, one Secret holds `databaseURL` and the S3 keys.
See [External PostgreSQL](/docs/installation/kubernetes/external-postgresql).

Unless `objectStorage.defaultCredentials` is on, Relic signs requests with the
static key pair from the Secret. The two bucket names must be different.
