## Hardening

- Pods run as user 65532 with a read-only root filesystem, no capabilities and
  no service account token.
- The worker accepts only metrics scrapes, from `metrics.allowScrapesFrom`
  (default: every pod). `networkPolicy.allowServerAccessFrom` limits access to
  the server. SeaweedFS has `seaweedfs.networkPolicy`.
- The SeaweedFS chart creates a ClusterRole
  (`seaweedfs.global.seaweedfs.createClusterRole`). Review it.
- Egress stays open for remote repositories. Relic refuses private upstream and
  replication addresses unless `RELIC_UPSTREAM_ALLOW_PRIVATE_ADDRESSES` is
  `true`.

## Probes

| Path | Reports |
| --- | --- |
| `/healthz` | The process is alive. |
| `/readyz` | The database and object storage answer. |

The probes follow `tls.enabled`. See also
[Troubleshooting](/docs/guides/operations#troubleshooting).
