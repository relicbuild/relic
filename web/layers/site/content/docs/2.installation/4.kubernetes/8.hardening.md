## Hardening

- Pods run as user 65532 with a read-only root filesystem, no capabilities and
  no service account token.
- NetworkPolicies block all incoming traffic to the worker except metrics
  scrapes on its metrics port while `metrics.enabled` is on (the default).
  `metrics.allowScrapesFrom` names who may scrape; left empty, it admits every
  pod in the cluster. `networkPolicy.allowServerAccessFrom` narrows who can
  reach the server.
  PostgreSQL and SeaweedFS use the settings of their own charts
  (`seaweedfs.networkPolicy`).
- The SeaweedFS chart creates a ClusterRole by default
  (`seaweedfs.global.seaweedfs.createClusterRole`). Review it for your cluster.
- Egress stays open, because remote repositories proxy arbitrary upstream URLs.
  Relic still refuses private upstream addresses unless
  `RELIC_UPSTREAM_ALLOW_PRIVATE_ADDRESSES` is `true`.

## Probes

| Path | Reports |
| --- | --- |
| `/healthz` | The process is alive. |
| `/readyz` | The database and object storage answer. |

The probes use HTTPS while `tls.enabled` is on, and HTTP otherwise.

If a pod stays unready, see [Troubleshooting](/docs/guides/operations#troubleshooting).
