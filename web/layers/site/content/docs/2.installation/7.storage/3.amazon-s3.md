## Create the buckets

Bucket names are global on AWS, so the names `artifacts` and `temporary` are
already taken. Pick your own names and set them in
`RELIC_OBJECT_STORAGE_ARTIFACTS_BUCKET` and
`RELIC_OBJECT_STORAGE_TEMPORARY_BUCKET`. Create both buckets in the region where
Relic runs.

This command creates the artifacts bucket:

```bash
aws s3api create-bucket --bucket example-relic-artifacts --region eu-central-1 \
  --create-bucket-configuration LocationConstraint=eu-central-1
```

This command creates the temporary bucket:

```bash
aws s3api create-bucket --bucket example-relic-temporary --region eu-central-1 \
  --create-bucket-configuration LocationConstraint=eu-central-1
```

New buckets have Block Public Access on and SSE-S3 encryption by default. Leave
versioning and Object Lock off on the artifacts bucket.

## Lifecycle rules

This rule expires everything in the temporary bucket after one day:

```bash
aws s3api put-bucket-lifecycle-configuration --bucket example-relic-temporary \
  --lifecycle-configuration '{"Rules":[{"ID":"expire-staged-uploads","Status":"Enabled","Filter":{},
    "Expiration":{"Days":1},"AbortIncompleteMultipartUpload":{"DaysAfterInitiation":1}}]}'
```

This rule cleans up incomplete multipart uploads in the artifacts bucket:

```bash
aws s3api put-bucket-lifecycle-configuration --bucket example-relic-artifacts \
  --lifecycle-configuration '{"Rules":[{"ID":"abort-incomplete-uploads","Status":"Enabled","Filter":{},
    "AbortIncompleteMultipartUpload":{"DaysAfterInitiation":1}}]}'
```

## IAM policy

Grant Relic this policy, through a role (below) or an IAM user's access key:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["s3:ListBucket"],
      "Resource": ["arn:aws:s3:::example-relic-artifacts", "arn:aws:s3:::example-relic-temporary"]
    },
    {
      "Effect": "Allow",
      "Action": ["s3:GetObject", "s3:PutObject", "s3:DeleteObject", "s3:AbortMultipartUpload"],
      "Resource": ["arn:aws:s3:::example-relic-artifacts/*", "arn:aws:s3:::example-relic-temporary/*"]
    }
  ]
}
```

Relic needs `s3:ListBucket`. Garbage collection lists the temporary bucket, and
the daily storage check lists the artifacts bucket. Without it, S3 also answers
`HeadObject` for a missing key with 403 instead of 404, and `/readyz` fails.

If you use SSE-KMS with a customer managed key, also allow `kms:GenerateDataKey`
and `kms:Decrypt` on that key.

## Credentials

Leave `RELIC_OBJECT_STORAGE_ACCESS_KEY` and `RELIC_OBJECT_STORAGE_SECRET_KEY`
empty, and Relic uses the AWS default credential chain: IAM roles for service
accounts (IRSA), EKS Pod Identity, the EC2 instance profile or ECS task role,
or the `AWS_*` environment variables. Credentials from these sources rotate on
their own. With a static key instead, rotate it by updating the Secret and
restarting the pods.

## Encryption and storage class

New buckets encrypt with SSE-S3 by default. To encrypt every object with a KMS
key, or to store objects in another storage class, set:

```ini
RELIC_OBJECT_STORAGE_SSE=aws:kms
RELIC_OBJECT_STORAGE_SSE_KMS_KEY_ID=alias/relic
RELIC_OBJECT_STORAGE_STORAGE_CLASS=INTELLIGENT_TIERING
```

Relic reads objects on demand, so avoid classes with retrieval delays (Glacier
Flexible Retrieval and Deep Archive).

## Settings

```ini
RELIC_OBJECT_STORAGE_REGION=eu-central-1
RELIC_OBJECT_STORAGE_ARTIFACTS_BUCKET=example-relic-artifacts
RELIC_OBJECT_STORAGE_TEMPORARY_BUCKET=example-relic-temporary
```

Leave `RELIC_OBJECT_STORAGE_ENDPOINT` empty: Relic then uses AWS's endpoint for
the region, with virtual-hosted-style URLs. The region must match the buckets'
region, or S3 rejects the signatures.

Helm, with IRSA on the service account:

```yaml
seaweedfs:
  enabled: false
serviceAccount:
  annotations:
    eks.amazonaws.com/role-arn: arn:aws:iam::<account>:role/relic
objectStorage:
  endpoint: ""
  region: eu-central-1
  defaultCredentials: true
  artifactsBucket: example-relic-artifacts
  temporaryBucket: example-relic-temporary
```

With a static key pair instead, the chart needs the endpoint. Leave out
`defaultCredentials`, set `objectStorage.endpoint` to
`https://s3.eu-central-1.amazonaws.com`, and put the keys in the Secret (see
[External object storage](/docs/installation/kubernetes/external-object-storage)).

## Costs on AWS

Every download is a `GetObject` that streams through Relic, and egress and
requests cost money. Once a day, the worker's storage check also lists the
artifacts bucket and reads up to 10 GiB of content back. Run Relic in the
buckets' region. Consider a VPC gateway
endpoint for S3, so the traffic skips the NAT gateway.
