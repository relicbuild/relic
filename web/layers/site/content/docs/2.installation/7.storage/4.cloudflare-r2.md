---
title: Cloudflare R2
description: Cloudflare R2 as object storage, through its S3-compatible API.
---

R2 has no egress fees, and every download reads from the bucket.

## Create the buckets

In the Cloudflare dashboard, under **R2 Object Storage**, create two buckets,
for example `relic-artifacts` and `relic-temporary`, with the same location
hint or jurisdiction. Leave public access and custom domains off.

This Wrangler command creates the artifacts bucket:

```bash
npx wrangler r2 bucket create relic-artifacts
```

This command creates the temporary bucket:

```bash
npx wrangler r2 bucket create relic-temporary
```

## Lifecycle rules

| Bucket | Rules (**Settings → Object lifecycle rules**) |
| --- | --- |
| relic-temporary | Delete objects 1 day after upload, and abort incomplete multipart uploads after 1 day. |
| relic-artifacts | Only abort incomplete multipart uploads. R2 adds a 7-day rule to new buckets. |

## API token

Under **R2 Object Storage → Manage API tokens**, create a token with **Object
Read & Write** permission on both buckets. Its **Access Key ID** and **Secret
Access Key**, shown once, are Relic's key pair.

## Settings

```ini
RELIC_OBJECT_STORAGE_ENDPOINT=https://<account-id>.r2.cloudflarestorage.com
RELIC_OBJECT_STORAGE_REGION=auto
RELIC_OBJECT_STORAGE_ARTIFACTS_BUCKET=relic-artifacts
RELIC_OBJECT_STORAGE_TEMPORARY_BUCKET=relic-temporary
RELIC_OBJECT_STORAGE_ACCESS_KEY=<access-key-id>
RELIC_OBJECT_STORAGE_SECRET_KEY=<secret-access-key>
```

`<account-id>` is on the R2 overview page. Buckets in a jurisdiction use its
endpoint, such as `https://<account-id>.eu.r2.cloudflarestorage.com`.

Helm:

```yaml
seaweedfs:
  enabled: false
existingCredentialsSecret: relic          # holds the S3 key pair, adminPassword and encryptionKey
objectStorage:
  endpoint: https://<account-id>.r2.cloudflarestorage.com
  region: auto
  artifactsBucket: relic-artifacts
  temporaryBucket: relic-temporary
```

## Gotchas

- **Region.** R2 signs with `auto`; it also accepts the default `us-east-1`.
- **Path-style URLs.** R2 supports the path-style requests Relic sends.
- **One token for both buckets.** A token scoped to one bucket makes every
  upload fail.
- **Checksums.** Upload a file of a few hundred megabytes after setup. If it
  fails with a checksum error, set `RELIC_OBJECT_STORAGE_CHECKSUM` to
  `when_required` (`objectStorage.checksum` in the Helm chart).
- **Latency.** Run Relic close to the buckets' location.
