---
title: MinIO
description: A self-hosted MinIO deployment as object storage.
---

MinIO implements the S3 API closely and works with the default settings. Relic
is not tested against MinIO, so run an upload and a download test before
production.

## Create the buckets, policy and user

These commands use the `mc` client with an alias `local` for the deployment.

This command creates the artifacts bucket:

```bash
mc mb local/relic-artifacts
```

This command creates the temporary bucket:

```bash
mc mb local/relic-temporary
```

This command expires objects in the temporary bucket after one day:

```bash
mc ilm rule add --expire-days 1 local/relic-temporary
```

Save this policy as `relic-policy.json`:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["s3:ListBucket"],
      "Resource": ["arn:aws:s3:::relic-artifacts", "arn:aws:s3:::relic-temporary"]
    },
    {
      "Effect": "Allow",
      "Action": ["s3:GetObject", "s3:PutObject", "s3:DeleteObject", "s3:AbortMultipartUpload"],
      "Resource": ["arn:aws:s3:::relic-artifacts/*", "arn:aws:s3:::relic-temporary/*"]
    }
  ]
}
```

This command creates the policy `relic` from the file:

```bash
mc admin policy create local relic relic-policy.json
```

This command creates the user `relic`:

```bash
mc admin user add local relic '<secret-key>'
```

This command attaches the policy to the user:

```bash
mc admin policy attach local relic --user relic
```

The user name is the access key.

## Settings

```ini
RELIC_OBJECT_STORAGE_ENDPOINT=https://minio.example.com:9000
RELIC_OBJECT_STORAGE_ARTIFACTS_BUCKET=relic-artifacts
RELIC_OBJECT_STORAGE_TEMPORARY_BUCKET=relic-temporary
RELIC_OBJECT_STORAGE_ACCESS_KEY=relic
RELIC_OBJECT_STORAGE_SECRET_KEY=<secret-key>
```

Leave `RELIC_OBJECT_STORAGE_REGION` at `us-east-1`, which is MinIO's default. If
the MinIO server sets a region (`MINIO_SITE_REGION`), use the same value.

Helm:

```yaml
seaweedfs:
  enabled: false
existingCredentialsSecret: relic          # holds the S3 key pair, adminPassword and encryptionKey
objectStorage:
  endpoint: https://minio.example.com:9000
  artifactsBucket: relic-artifacts
  temporaryBucket: relic-temporary
```

## Gotchas

- **Path-style.** Relic sends path-style requests, which MinIO serves by default.
  You do not need `MINIO_DOMAIN`.
- **TLS.** Relic trusts only the system CA bundle, and there is no custom CA
  setting. A MinIO certificate from a private CA fails verification. Use a
  publicly trusted certificate, or keep MinIO on a private network over plain
  HTTP.
- **Versioning.** Leave versioning off on the artifacts bucket, or add an
  `mc ilm` rule that expires noncurrent versions. Otherwise garbage collection
  frees no space.
- **Old releases.** Uploads carry the AWS SDK's newer default checksums. Very old
  MinIO releases may reject them. Keep MinIO up to date, or set
  `RELIC_OBJECT_STORAGE_CHECKSUM` to `when_required` (`objectStorage.checksum`
  in the Helm chart), which sends checksums only where S3 requires them.
