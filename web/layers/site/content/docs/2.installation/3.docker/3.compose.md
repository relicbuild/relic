---
title: Docker Compose
description: Run Relic, PostgreSQL and SeaweedFS on one machine for development and evaluation.
---

`deploy/docker-compose.yml` runs the server, the worker, PostgreSQL and a small
SeaweedFS cluster on one machine. The cluster has a master, two volume servers,
a filer and the S3 gateway.

The stack is for development and evaluation only. Its credentials are public.
Do not expose it, and do not keep data you need in it.

## Start

From a checkout of the repository, build and start the stack:

```bash
docker compose -f deploy/docker-compose.yml up --build
```

Compose builds the image from the repository's `Dockerfile`. The image holds the
web UI, the Go binary, the scanners and the indexer builds. The first start takes
a few minutes.

The server serves HTTPS at `https://localhost:8090`, with a certificate
authority it generates in the `relic-tls` volume
([TLS](/docs/installation/configuration#tls)). Copy the authority's certificate
out of the server:

```bash
docker compose -f deploy/docker-compose.yml cp relic-server:/etc/relic/tls/ca.crt .
```

Trust `ca.crt` in your browser or system, open `https://localhost:8090` and
sign in as `admin` with the password `password`.

Sign in with the relic CLI:

```bash
echo password | relic auth login https://localhost:8090 --user admin --password-stdin --context relic-dev --ca-file ca.crt
```

Check the sign-in:

```bash
relic auth status
```

## Services

| Service | Notes |
| --- | --- |
| `relic-server` | The server, over HTTPS on `127.0.0.1:8090`. It keeps its certificate authority in the `relic-tls` volume, and its certificate also holds the name `relic-server`. |
| `relic-worker` | The worker. It keeps Grype's database in the `vulnerability-database` volume. |
| `postgresql` | PostgreSQL 18, on `127.0.0.1:5432`. |
| `seaweedfs-master`, `seaweedfs-volume-1`, `seaweedfs-volume-2`, `seaweedfs-filer` | SeaweedFS, replication `001` (one extra copy on the other volume server). |
| `seaweedfs-s3` | The S3 gateway, on `127.0.0.1:8333`. Its identities are in `deploy/seaweedfs/s3.json`. |
| `seaweedfs-create-buckets` | A job that runs once. It creates the `artifacts` and `temporary` buckets and gives `temporary` a one-day TTL. |

All ports bind to `127.0.0.1` only.

[Compose settings](/docs/installation/docker/compose-settings) lists the
settings. To use Amazon S3, R2, MinIO or another store instead of SeaweedFS, see
[Another object store](/docs/installation/docker/compose-other-object-storage).

## Single node

`deploy/docker-compose.single-node.yml` turns the stack into one container that
uses SQLite and a volume, without PostgreSQL or SeaweedFS. Start it:

```bash
docker compose -f deploy/docker-compose.yml -f deploy/docker-compose.single-node.yml up --build relic-server
```

## Stop and reset

Stop the stack and keep the data volumes:

```bash
docker compose -f deploy/docker-compose.yml down
```

Stop the stack and delete all data:

```bash
docker compose -f deploy/docker-compose.yml down -v
```
