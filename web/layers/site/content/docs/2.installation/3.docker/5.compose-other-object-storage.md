---
title: Compose with another object store
description: Run the Compose stack against Amazon S3, R2, MinIO or another S3-compatible store.
---

1. Remove the SeaweedFS services and every `depends_on` naming them.
2. Set both Relic services' storage variables
   ([Storage](/docs/installation/storage/overview)):

```yaml
RELIC_OBJECT_STORAGE_ENDPOINT: https://s3.eu-central-1.amazonaws.com
RELIC_OBJECT_STORAGE_REGION: eu-central-1
RELIC_OBJECT_STORAGE_ARTIFACTS_BUCKET: example-relic-artifacts
RELIC_OBJECT_STORAGE_TEMPORARY_BUCKET: example-relic-temporary
RELIC_OBJECT_STORAGE_ACCESS_KEY: <access-key>
RELIC_OBJECT_STORAGE_SECRET_KEY: <secret-key>
```
