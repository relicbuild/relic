---
title: Compose with another object store
description: Run the Compose stack against Amazon S3, R2, MinIO or another S3-compatible store instead of SeaweedFS.
---

1. Remove the SeaweedFS services. Also remove `seaweedfs-create-buckets` and
   `seaweedfs-s3` from the `depends_on` of `relic-server`.
2. Set the `RELIC_OBJECT_STORAGE_*` variables of both Relic services as the
   [storage pages](/docs/installation/storage/overview) describe.

Example `environment` for both Relic services:

```yaml
RELIC_OBJECT_STORAGE_ENDPOINT: https://s3.eu-central-1.amazonaws.com
RELIC_OBJECT_STORAGE_REGION: eu-central-1
RELIC_OBJECT_STORAGE_ARTIFACTS_BUCKET: example-relic-artifacts
RELIC_OBJECT_STORAGE_TEMPORARY_BUCKET: example-relic-temporary
RELIC_OBJECT_STORAGE_ACCESS_KEY: <access-key>
RELIC_OBJECT_STORAGE_SECRET_KEY: <secret-key>
```
