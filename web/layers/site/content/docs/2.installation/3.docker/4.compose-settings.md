---
title: Compose settings
description: Ports, passwords and worker timings of the Compose stack.
---

Compose reads these variables from the shell or from `deploy/.env`:

| Variable | Default | Meaning |
| --- | --- | --- |
| `RELIC_PORT` | `8090` | Host port of the server, which serves HTTPS. |
| `RELIC_POSTGRESQL_PORT` | `5432` | Host port of PostgreSQL. |
| `RELIC_OBJECT_STORAGE_PORT` | `8333` | Host port of the S3 gateway. |
| `RELIC_DATABASE_PASSWORD` | `relic` | PostgreSQL password. |
| `RELIC_ADMIN_PASSWORD` | `password` | First administrator's password. Applies only while no user exists. |
| `RELIC_ENCRYPTION_KEY` | a development key | Seals secrets in the database. See [Secrets at rest](/docs/guides/operations#secrets-at-rest). |
| `RELIC_UPSTREAM_ALLOW_PRIVATE_ADDRESSES` | `true` | Lets remote repositories connect to private addresses. |
| `RELIC_WEBHOOK_ALLOW_PRIVATE_ADDRESSES` | `true` | Lets webhooks deliver to private addresses. |
| `RELIC_TRASH_ENABLED` | `true` | `false` makes deletes permanent. |
| `RELIC_TRUSTED_PROXIES` | the private ranges and loopback | Proxies whose `X-Forwarded-*` headers Relic trusts. |
| `RELIC_FAILED_SIGN_INS_BEFORE_BACKOFF` | `20` | Failed password attempts a client address may make within ten minutes before each further attempt waits. |
| `RELIC_DATABASE_MAX_CONNECTIONS` | `20` | The most PostgreSQL connections the server opens. |
| `RELIC_GARBAGE_COLLECTION_INTERVAL`, `RELIC_GARBAGE_COLLECTION_GRACE_PERIOD`, `RELIC_TRASH_RETENTION` | `10m`, `1h`, `336h` | Worker timings. |
| `RELIC_OTLP_ENDPOINT` | (none) | Where to send traces. Set it to `http://otel-collector:4318` with the observability profile. |
| `RELIC_LOG_LEVEL` | `info` | Log level. |
| `RELIC_PROFILING_ENABLED` | `false` | `true` adds `/debug/pprof/` to the metrics listener of the server and the worker. |
| `RELIC_GRAFANA_PORT`, `RELIC_PROMETHEUS_PORT` | `3000`, `9090` | Host ports of Grafana and Prometheus (observability profile). |
| `GRAFANA_ADMIN_PASSWORD` | `admin` | Grafana's admin password (observability profile). |

The [configuration reference](/docs/installation/configuration) lists the other
settings, `RELIC_AUDIT_RETENTION` among them. Set them in the `environment` of the
`relic-server` and `relic-worker` services.

The `relic-server` service sets `RELIC_TLS_HOSTNAMES` to `relic-server` and keeps
its certificate authority in the `relic-tls` volume, mounted at `/etc/relic/tls`
([TLS](/docs/installation/configuration#tls)).

## Observability profile

The `observability` profile adds:

| Service | Role |
| --- | --- |
| OpenTelemetry Collector | Sends traces to Tempo. |
| Tempo | Stores traces. It keeps every trace. |
| Loki with Alloy | Collects the containers' logs from the Docker socket. |
| Prometheus | Scrapes Relic, SeaweedFS and a PostgreSQL exporter, and loads Relic's alert rules. |
| Grafana | Comes provisioned with the datasources and Relic's dashboards. |

Start the stack with the observability profile and send traces to the collector:

```bash
RELIC_OTLP_ENDPOINT=http://otel-collector:4318 \
  docker compose -f deploy/docker-compose.yml --profile observability up --build
```

Grafana is at `http://127.0.0.1:3000`. Sign in as `admin` with the password
from `GRAFANA_ADMIN_PASSWORD`. Prometheus is at `http://127.0.0.1:9090`.

Relic's metrics endpoint listens on port 8091 inside the Compose network only
(`http://relic-server:8091/metrics`).
