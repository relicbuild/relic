---
title: NuGet
description: Restore and push NuGet packages with dotnet and nuget.exe, over a V3 or V2 feed.
---

This command runs `dotnet nuget add source`, naming the source after the repository:

```bash
relic package setup nuget nuget --write
```

Restore packages:

```bash
dotnet restore
```

By hand, add the V3 feed to `nuget.config`:

```xml
<configuration>
  <packageSources><clear />
    <add key="relic" value="https://relic.example.com/nuget/nuget/index.json" protocolVersion="3" />
  </packageSources>
  <packageSourceCredentials><relic>
    <add key="Username" value="<you>" /><add key="ClearTextPassword" value="<token>" />
  </relic></packageSourceCredentials>
</configuration>
```

Push a package (`--source relic` with the `nuget.config` above):

```bash
dotnet nuget push <pkg> --source nuget --api-key <you>:<token>
```

- A push to a virtual repository goes to its default deployment repository; `dotnet nuget delete` moves a version to the trash can.
- The V2 feed is `https://relic.example.com/nuget/nuget` (`protocolVersion="2"`).
