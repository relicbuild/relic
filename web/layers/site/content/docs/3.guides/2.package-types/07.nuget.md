---
title: NuGet
description: dotnet and nuget.exe against a NuGet V3 or V2 feed.
---

This command runs `dotnet nuget add source` with your credentials:

```bash
relic package setup nuget nuget --write
```

`dotnet` then restores packages from the repository:

```bash
dotnet restore
```

The V3 feed is `https://relic.example.com/nuget/nuget/index.json`. To configure it by hand,
add it to `nuget.config`:

```xml
<!-- nuget.config -->
<configuration>
  <packageSources><clear />
    <add key="relic" value="https://relic.example.com/nuget/nuget/index.json" protocolVersion="3" />
  </packageSources>
  <packageSourceCredentials><relic>
    <add key="Username" value="<you>" /><add key="ClearTextPassword" value="<token>" />
  </relic></packageSourceCredentials>
</configuration>
```

- `dotnet nuget push <pkg> --source nuget --api-key <you>:<token>` publishes a package.
  `relic package setup` names the source after the repository (`nuget` here); with the
  `nuget.config` above, use `--source relic`. On a virtual repository, the package goes to
  its default deployment repository.
- `dotnet nuget delete` moves a version to the trash can.
- The V2 feed is `https://relic.example.com/nuget/nuget` (`protocolVersion="2"`).
