---
title: Maven and Gradle
description: Resolve and deploy Java artifacts with Maven and Gradle; virtual repositories merge metadata.
---

This command writes `~/.m2/settings.xml`: a mirror through the repository, with credentials:

```bash
relic package setup maven maven --write
```

To deploy, add `distributionManagement` to `pom.xml`, with the repository's name as server id:

```xml
<distributionManagement>
  <repository><id>maven</id><url>https://relic.example.com/maven/maven</url></repository>
  <snapshotRepository><id>maven</id><url>https://relic.example.com/maven/maven</url></snapshotRepository>
</distributionManagement>
```

Deploy:

```bash
mvn deploy
```

This command writes `relicUrl`, `relicUser` and `relicToken` to `~/.gradle/gradle.properties`:

```bash
relic package setup gradle maven --write
```

By hand, add a mirror to `settings.xml`, and a `<server>` of the same id with credentials:

```xml
<mirror><id>relic</id><mirrorOf>*</mirrorOf><url>https://relic.example.com/maven/maven</url></mirror>
```

For Gradle by hand, add an init script to `~/.gradle/init.d/`:

```groovy
def relic = { MavenArtifactRepository repo ->
    repo.url = uri("https://relic.example.com/maven/maven")
    repo.credentials { username = "<you>"; password = "<token>" }
}
settingsEvaluated { it.pluginManagement.repositories { maven { relic(it) } } }
allprojects { repositories { maven { relic(it) } } }
```

- For a private CA ([TLS](/docs/installation/configuration#tls)), add the CA certificate to
  the JVM's trust store.
- Relic generates `maven-metadata.xml`; a snapshot's metadata points at its newest upload.
  Virtual repositories merge their members' metadata.
- A POM or JAR has a **Dependency** tab (Maven, Gradle, Ivy, SBT) and an **Archive** tab.
