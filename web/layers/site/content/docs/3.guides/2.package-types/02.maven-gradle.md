---
title: Maven and Gradle
description: Resolve and deploy Java artifacts, with merged maven-metadata.xml on virtual repositories.
---

This command writes `~/.m2/settings.xml` with a mirror that points at the repository, and your credentials:

```bash
relic package setup maven maven --write
```

The mirror covers resolving only. To deploy, point the project's
`distributionManagement` in `pom.xml` at the repository, with the server id the
command wrote (the repository's name):

```xml
<distributionManagement>
  <repository><id>maven</id><url>https://relic.example.com/maven/maven</url></repository>
  <snapshotRepository><id>maven</id><url>https://relic.example.com/maven/maven</url></snapshotRepository>
</distributionManagement>
```

Then deploy with Maven:

```bash
mvn deploy
```

For Gradle, this command writes `relicUrl`, `relicUser` and `relicToken` to `~/.gradle/gradle.properties`:

```bash
relic package setup gradle maven --write
```

To configure Maven by hand, add a mirror to `settings.xml`. Put the credentials in a `<server>`
entry with the same id:

```xml
<mirror><id>relic</id><mirrorOf>*</mirrorOf><url>https://relic.example.com/maven/maven</url></mirror>
```

To configure Gradle by hand, add an init script to `~/.gradle/init.d/`:

```groovy
def relic = { MavenArtifactRepository repo ->
    repo.url = uri("https://relic.example.com/maven/maven")
    repo.credentials { username = "<you>"; password = "<token>" }
}
settingsEvaluated { it.pluginManagement.repositories { maven { relic(it) } } }
allprojects { repositories { maven { relic(it) } } }
```

- If Relic's certificate comes from a private CA, such as the one Relic generates
  ([TLS](/docs/installation/configuration#tls)), add the CA certificate to the trust store of
  the JVM that runs Maven or Gradle.
- Relic generates `maven-metadata.xml` from the files it holds. Maven names each snapshot
  upload with a timestamp and build number, and the snapshot's metadata points at the newest.
- Virtual repositories merge their members' metadata.
- In the UI, a POM or JAR has a **Dependency** tab with Maven, Gradle, Ivy and SBT
  snippets. It also has an **Archive** tab that lists the JAR's contents.
