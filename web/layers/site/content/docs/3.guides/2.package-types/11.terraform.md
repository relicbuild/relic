This command writes your credentials and the providers' network mirror to `~/.terraformrc`
(`%APPDATA%\terraform.rc` on Windows), or to the file `TF_CLI_CONFIG_FILE` names:

```bash
relic package setup terraform terraform --write
```

Terraform then installs providers through Relic:

```bash
terraform init
```

## Providers

To configure Terraform by hand, point the CLI configuration at a Terraform repository.
The CLI configuration is `~/.terraformrc`, or the file `TF_CLI_CONFIG_FILE` names:

```hcl
provider_installation {
  network_mirror { url = "https://relic.example.com/terraform/terraform/providers/" }
}
credentials "relic.example.com" { token = "<token>" }
```

| Repository | Serves |
| --- | --- |
| Remote of `https://registry.terraform.io` (OpenTofu: `https://registry.opentofu.org`) | Public providers, proxied, with their packages cached. |
| Local | What `terraform providers mirror <dir>` writes. Upload the directory as is (`<hostname>/<namespace>/<type>/terraform-provider-…zip`). |
| Virtual | Both combined. |

## Modules

This command publishes a module from a directory:

```bash
relic package publish terraform tf-local 1.0.0 --namespace acme --provider aws --dir modules/network
```

Reference a module as `source = "relic.example.com/<repo>__<namespace>/<name>/<provider>"`. For
example: `source = "relic.example.com/tf-local__acme/network/aws"`.
