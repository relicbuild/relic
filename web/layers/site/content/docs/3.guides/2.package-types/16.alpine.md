---
title: Alpine
description: Alpine repositories for apk, with signed indexes.
---

An Alpine repository serves the `APKINDEX.tar.gz` apk reads, generated for each
folder from the packages in it and signed with the repository's RSA key pair.
Packages go in folders laid out as on Alpine's mirrors,
`<version>/<repository>/<architecture>/`, for example `v3.21/main/x86_64/`.

Upload a package to a local repository:

```bash
relic artifact upload hello-1.0-r0.apk alpine-local/v3.21/main/x86_64/hello-1.0-r0.apk
```

As root, for example in an image build, add the repository to
`/etc/apk/repositories` with your token, and save its public key in
`/etc/apk/keys/`:

```bash
relic package setup apk alpine --branch v3.21 --write
```

To configure apk by hand, save the repository's public key. Relic serves it on its
JFrog® Artifactory® API. apk finds the key by the key pair's name, `relic-rsa` unless the
repository names its own signing key, so the file is named after it:

```bash
curl -fsSL -u <you>:<token> -o /etc/apk/keys/relic-rsa.rsa.pub https://relic.example.com/artifactory/api/security/keypair/public/repositories/alpine
```

Then add the repository to `/etc/apk/repositories`, with your token:

```text
https://<you>:<token>@relic.example.com/alpine/alpine/v3.21/main
```

Update apk's indexes:

```bash
apk update
```

Install a package through Relic:

```bash
apk add hello
```

- `signingKey` names the key pair that signs a local or virtual repository's
  indexes. Relic creates it, as an RSA key pair, the first time it signs with it,
  so it cannot also sign an RPM or Debian repository. Without `signingKey`, Relic
  signs with its default key pair, `relic-rsa`.
- A remote repository proxies an upstream, for example
  `https://dl-cdn.alpinelinux.org/alpine`. It serves the upstream's signed indexes
  unchanged, so apk checks them with Alpine's keys, which Alpine systems already
  trust.
- A virtual repository merges its members' indexes, a remote member's upstream
  index included, and signs the result.
- A `noarch` package is listed under its folder's architecture.
- Through the JFrog Artifactory API, `primaryKeyPairRef` is the signing key.
  `jf apk upload` puts a package in its folder.
