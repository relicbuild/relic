---
title: Debian
description: APT repositories for apt and apt-get, with signed indexes.
---

A Debian repository serves the indexes apt reads, generated from the packages it
holds: for each distribution, a `Release` file under `dists/<distribution>/`, signed
with the repository's key pair (`InRelease`, `Release.gpg`), and the `Packages` index
of each component and architecture.

Upload a package to a local repository, to any folder:

```bash
relic artifact upload hello_2.10-3_amd64.deb debian-local/pool/main/h/hello/hello_2.10-3_amd64.deb
```

Place it in a distribution. The component defaults to `main`, and the architecture
to the package's own:

```bash
relic artifact props set debian-local/pool/main/h/hello/hello_2.10-3_amd64.deb deb.distribution=bookworm deb.component=main
```

As root, configure apt for a distribution of the repository. The command writes the
source, your token in `/etc/apt/auth.conf.d/`, and the repository's public key:

```bash
relic package setup apt debian --distribution bookworm --write
```

`--components` names components other than `main`, space-separated.

Update apt's package lists:

```bash
apt-get update
```

Install a package through Relic:

```bash
apt-get install hello
```

To configure apt by hand, save the repository's public key. Relic serves it on its
JFrog® Artifactory® API:

```bash
curl -fsSL -u <you>:<token> -o /etc/apt/keyrings/relic.asc https://relic.example.com/artifactory/api/security/keypair/public/repositories/debian
```

Add the source, in `/etc/apt/sources.list.d/relic.list`:

```text
deb [signed-by=/etc/apt/keyrings/relic.asc] https://relic.example.com/debian/debian bookworm main
```

Add your credentials to `/etc/apt/auth.conf.d/relic.conf`, readable by root only:

```text
machine relic.example.com login <you> password <token>
```

A virtual repository merges its members' indexes and signs the result. From its
remote members it takes only the architectures `architectures` lists, `amd64` and
`arm64` by default, as a full mirror has many more:

```yaml
apiVersion: relic.build/v1
kind: Repository
metadata:
  name: debian
spec:
  class: virtual
  format: debian
  architectures: [amd64]
  signingKey: debian-signing
  virtual:
    members: [debian-local, debian-remote]
    deployTo: debian-local
```

- A local repository places each `.deb` by its properties: `deb.distribution`
  (required), `deb.component` (`main` when unset) and `deb.architecture` (the
  package's `Architecture` when unset). A package for `all` is listed under every
  architecture.
- A remote repository proxies an upstream, for example `https://deb.debian.org/debian`.
  It serves the upstream's signed indexes unchanged, so apt checks them with the
  upstream's key, which that distribution's systems already trust.
- `signingKey` names the key pair that signs a local or virtual repository's
  indexes. Relic creates it, as an OpenPGP key pair, the first time it signs with
  it. Without `signingKey`, Relic signs with its default key pair, `relic-gpg`.
- A virtual repository's indexes can lag its members by up to 30 seconds.
- Through the JFrog Artifactory API, `debianArchitectures` is `architectures` and
  `primaryKeyPairRef` is the signing key. `jf rt upload --deb bookworm/main/amd64`
  sets the three properties as it uploads.
