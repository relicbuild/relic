This command writes the token where `huggingface_hub` reads it (the file
`HF_TOKEN_PATH` names, `$HF_HOME/token`, `$XDG_CACHE_HOME/huggingface/token`,
or `~/.cache/huggingface/token`), and prints the `HF_ENDPOINT` to export:

```bash
relic package setup huggingface hf --write
```

Export the endpoint:

```bash
export HF_ENDPOINT=https://relic.example.com/huggingface/hf
```

## Supported clients

`huggingface_hub` 1.x and 2.x upload and download, with or without
`hf_xet` installed, and so do the tools built on it (the `hf` command,
`transformers`, `datasets`).

## Xet storage

With `hf_xet` installed, `huggingface_hub` 1.20.0 and later upload files
stored with Git LFS through Hugging Face's Xet protocol. Relic serves that
protocol itself:

- The client asks the repository for a Xet token. Relic checks the
  caller may deploy to the repository (or read it, for a read token) and
  issues a token that is valid for an hour, for that repository only.
- The client splits each file into chunks and uploads them packed in
  xorbs. Relic checks every chunk and the xorb's hash before storing it in
  the deployment repository, under `.hf-xet/xorbs/`.
- The client then registers its files. Relic checks each file's chunk
  ranges and hashes, and rebuilds the file into an ordinary item, with its
  SHA-256 checked, before the commit adds it to the model or dataset.

A model uploaded through Xet is stored like any other file: it keeps its
checksums and properties, the scanners check it, and every client, Xet or
not, downloads it byte for byte over HTTP. Chunks a client uploaded to the
repository before are not uploaded again: the client references the xorbs
that already hold them. Relic does not answer Xet's global deduplication
queries, so deduplication works against what the same client uploaded.

You can also upload and download without huggingface_hub.

This command uploads a directory as a new commit of `main`:

```bash
relic package huggingface upload ./bert-tiny hf-local acme/bert-tiny
```

This command downloads `google-bert/bert-base-uncased` at revision `main`:

```bash
relic package huggingface download hf-remote google-bert/bert-base-uncased ./bert --revision main
```
