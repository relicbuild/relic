title: Docker and OCI
description: Push and pull images, with the repository as the first path segment.
---

This command runs `docker login` and passes the token on standard input:

```bash
relic package setup docker docker --write
```

Push an image to a local repository:

```bash
docker push relic.example.com/docker-local/app:1.0
```

Pull an image through a virtual or remote repository:

```bash
docker pull relic.example.com/docker/nginx:1.27
```

Record the pushed image in a build:

```bash
relic build add-image app 1 docker-local/app:1.0
```

`relic package setup podman` logs Podman in the same way.

If Relic's certificate comes from a private CA, such as the one Relic generates
([TLS](/docs/installation/configuration#tls)), put the CA certificate in
`/etc/docker/certs.d/<host:port>/ca.crt` on each machine that runs Docker.

- A remote repository pointing at `https://registry-1.docker.io` caches Docker Hub,
  including official images (`library/`).
- Relic stores multi-platform images (indexes) together with their platform manifests.
- The registry follows the OCI distribution specification 1.1 and passes its
  conformance suite.
- The referrers API, `GET /v2/<repo>/<image>/referrers/<digest>`, lists artifacts that have
  a `subject`. These are signatures, SBOMs and attestations pushed by `oras` or `cosign`.
  Add `?artifactType=` to filter the list.
- In the UI, a tag has a **Docker** tab with its layers, build steps and labels. It also
  has a **Security** tab with the image's vulnerabilities.

## Kubernetes

Pods pull images from Relic with an image pull secret. This command creates the secret:

```bash
kubectl create secret docker-registry relic --docker-server=relic.example.com \
  --docker-username=<you> --docker-password=<token>
```

Reference the secret in the pod spec:

```yaml
spec:
  imagePullSecrets: [{name: relic}]
  containers: [{name: app, image: "relic.example.com/docker/app:1.0"}]
```

If Relic serves HTTPS with a certificate the nodes trust, containerd needs no other setup.
For plain HTTP or a privately signed certificate, add
`/etc/containerd/certs.d/relic.example.com/hosts.toml` on each node. On k3s, add an entry to
`/etc/rancher/k3s/registries.yaml` instead.
