---
title: Cargo
description: A sparse Cargo registry for crates.
---

This command adds the repository to `~/.cargo/config.toml` as a registry named after it
(`cargo` here), and its token to `credentials.toml`:

```bash
relic package setup cargo cargo --write
```

Publish a crate to it:

```bash
cargo publish --registry cargo
```

To fetch crates.io dependencies through Relic too, add this to `~/.cargo/config.toml`:

```toml
[source.crates-io]
replace-with = "cargo"
```

Cargo then fetches crates through Relic:

```bash
cargo build
```

The sparse registry is `sparse+https://relic.example.com/cargo/cargo/index/`. To configure
Cargo by hand, add it to `~/.cargo/config.toml`:

```toml
# ~/.cargo/config.toml
[registry]
global-credential-providers = ["cargo:token"]
[registries.relic]
index = "sparse+https://relic.example.com/cargo/cargo/index/"
[source.crates-io]
replace-with = "relic"
```

- With this configuration, `echo "Bearer <token>" | cargo login --registry relic` stores the
  token, and `cargo publish --registry relic` publishes.
- A virtual Cargo repository merges its members' indexes, for example a local repository
  and a remote of `https://index.crates.io`.
- A crate published to a virtual repository goes to its default deployment repository.
