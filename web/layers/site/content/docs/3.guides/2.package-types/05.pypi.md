This command writes the index URL to the `pip.conf` pip reads on your system
(`~/.config/pip`, `~/Library/Application Support/pip` on macOS when that folder
exists, `%APPDATA%\pip\pip.ini` on Windows) and your credentials to `~/.netrc`:

```bash
relic package setup pip pypi --write
```

pip then installs packages from the repository:

```bash
pip install requests
```

This command configures twine in `~/.pypirc`:

```bash
relic package setup twine pypi-local --write
```

Upload packages with twine:

```bash
twine upload --repository pypi-local dist/*
```

`relic package setup poetry` and `relic package setup pipenv` configure Poetry and Pipenv.

## pip by hand

Set the index URL, with your credentials, in `pip.conf`:

```ini
[global]
index-url = https://<you>:<token>@relic.example.com/pypi/pypi/simple
```

## uv

Add the index to `pyproject.toml`:

```toml
[[tool.uv.index]]
name = "relic"
url = "https://relic.example.com/pypi/pypi/simple"
default = true
```

Put the credentials in the environment:

```bash
export UV_INDEX_RELIC_USERNAME=<you> UV_INDEX_RELIC_PASSWORD=<token>
```

Then lock the dependencies:

```bash
uv lock
```

Install them:

```bash
uv sync --frozen
```

## Poetry

Add the repository as Poetry's primary source:

```bash
poetry source add --priority=primary relic https://relic.example.com/pypi/pypi/simple
```

Store your credentials for it:

```bash
poetry config http-basic.relic <you> <token>
```

## A remote of PyPI

PyPI keeps its index at `https://pypi.org` and its files at
`https://files.pythonhosted.org`. A remote of PyPI has the file host as its
`url`, and its `indexUrl` defaults to `https://pypi.org`:

```yaml
apiVersion: relic.build/v1
kind: Repository
metadata:
  name: pypi-remote
spec:
  class: remote
  format: pypi
  remote:
    url: https://files.pythonhosted.org
```

A remote whose `url` is `https://pypi.org` works the same: Relic fetches its
files from `https://files.pythonhosted.org`. For another index, set `url` to
the host its files are on and `indexUrl` to the index.

## Notes

- Uploading a file that already exists needs delete (overwrite) permission. Without it,
  the server answers 409. `twine upload --skip-existing` treats a 409 as already uploaded.
- If Relic's certificate comes from a private CA, such as the one Relic generates
  ([TLS](/docs/installation/configuration#tls)), point pip at the CA certificate with
  `--cert` or `PIP_CERT`. Point uv at the system certificate store with `SSL_CERT_FILE` or
  `UV_NATIVE_TLS=1`. Point twine and poetry at it with `REQUESTS_CA_BUNDLE`.
- In the UI, a wheel or sdist has a **PyPI** tab with its metadata: requirements,
  license and classifiers.
