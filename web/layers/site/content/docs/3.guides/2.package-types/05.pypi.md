---
title: PyPI
description: Install and upload Python packages through a PyPI repository, with pip, uv, Poetry or twine.
---

This command writes the index URL to pip's configuration file and your credentials to `~/.netrc`:

```bash
relic package setup pip pypi --write
```

Install a package:

```bash
pip install requests
```

This command configures twine in `~/.pypirc`:

```bash
relic package setup twine pypi-local --write
```

Upload with twine:

```bash
twine upload --repository pypi-local dist/*
```

`relic package setup poetry` and `relic package setup pipenv` configure Poetry and Pipenv.
Poetry reserves the name `pypi` for PyPI, so setup names a repository called `pypi`
`relic-pypi` in Poetry's configuration.

## pip by hand

In `pip.conf`:

```ini
[global]
index-url = https://<you>:<token>@relic.example.com/pypi/pypi/simple
```

## uv

Add the index to `pyproject.toml`:

```toml
[[tool.uv.index]]
name = "relic"
url = "https://relic.example.com/pypi/pypi/simple"
default = true
```

Set the credentials:

```bash
export UV_INDEX_RELIC_USERNAME=<you> UV_INDEX_RELIC_PASSWORD=<token>
```

Lock the dependencies:

```bash
uv lock
```

Install them:

```bash
uv sync --frozen
```

## Poetry

Add the primary source:

```bash
poetry source add --priority=primary relic https://relic.example.com/pypi/pypi/simple
```

Store your credentials:

```bash
poetry config http-basic.relic <you> <token>
```

## A remote of PyPI

A remote of PyPI has the file host as `url`; `indexUrl` defaults to `https://pypi.org`:

```yaml
apiVersion: relic.build/v1
kind: Repository
metadata:
  name: pypi-remote
spec:
  class: remote
  format: pypi
  remote:
    url: https://files.pythonhosted.org
```

A `url` of `https://pypi.org` also works. For another index, set `url` to its file host and `indexUrl` to the index.

## Notes

- Replacing an existing file needs delete permission; without it the server answers `409`,
  which `twine upload --skip-existing` skips.
- For a private CA ([TLS](/docs/installation/configuration#tls)): pip takes `--cert` or
  `PIP_CERT`, uv `SSL_CERT_FILE` or `UV_NATIVE_TLS=1`, twine and Poetry `REQUESTS_CA_BUNDLE`.
