---
title: RubyGems
description: gem and Bundler against a gems repository.
---

This command configures Bundler to mirror rubygems.org through the repository:

```bash
relic package setup ruby gems --write
```

Bundler then installs gems through Relic:

```bash
bundle install
```

To configure gem and Bundler by hand, first fetch an API key into `~/.gem/credentials`:

```bash
curl -u <you>:<password> https://relic.example.com/gems/gems/api/v1/api_key.yaml > ~/.gem/credentials
```

Restrict the file to your user:

```bash
chmod 600 ~/.gem/credentials
```

Push a gem:

```bash
gem push my_gem-1.0.0.gem --host https://relic.example.com/gems/gems --key rubygems
```

Give Bundler your credentials for the repository:

```bash
bundle config set --global https://relic.example.com/gems/gems/ <you>:<token>
```

- `gem sources -a https://relic.example.com/gems/gems/` adds the repository as a source.
- `api_key.yaml` and `gem signin` return a new access token. They do not return your password.
- `gem yank` moves the gem to the trash can.
