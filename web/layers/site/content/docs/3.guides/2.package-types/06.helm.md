title: Helm

This command runs `helm repo add` with your token, naming the Helm repository
after the Relic repository (`helm` here):

```bash
relic package setup helm helm --write
```

Update the repository index:

```bash
helm repo update
```

Install a chart from it:

```bash
helm install web helm/web
```

Publish a chart by uploading its archive to a local repository:

```bash
relic artifact upload web-1.4.0.tgz helm-local/web-1.4.0.tgz
```

- Relic generates `index.yaml` from the repository's charts. A virtual repository merges
  the `index.yaml` of its members.
- In the UI, a chart has a **Helm** tab that shows its `Chart.yaml`: dependencies,
  maintainers and the app version.

## OCI charts

A Helm OCI repository (format `helmoci`) is an OCI registry for charts. For one, this
command runs `helm registry login` with your token:

```bash
relic package setup helm helm-oci --write
```

To log in by hand, give your token as the password:

```bash
helm registry login relic.example.com --username <you>
```

Push a packaged chart:

```bash
helm push web-1.4.0.tgz oci://relic.example.com/helm-oci
```

Install it:

```bash
helm install web oci://relic.example.com/helm-oci/web --version 1.4.0
```

A Helm repository also accepts OCI pushes. `index.yaml` lists only the charts uploaded as
archives.
