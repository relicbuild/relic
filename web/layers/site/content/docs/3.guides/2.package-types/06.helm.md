---
title: Helm
description: Serve Helm charts from a repository with a generated index.yaml, or from an OCI registry.
---

This command runs `helm repo add` with your token, under the repository's name:

```bash
relic package setup helm helm --write
```

Install a chart:

```bash
helm install web helm/web
```

Publish a chart archive to a local repository:

```bash
relic artifact upload web-1.4.0.tgz helm-local/web-1.4.0.tgz
```

- Relic generates `index.yaml`; a virtual repository merges its members'.
- A remote's `index.yaml` points every chart at Relic. Charts the upstream index lists on another
  host (GitHub release downloads, for example) are served under
  `_upstream/<host>/<path>` and fetched and cached on first use; Relic fetches only URLs the
  upstream index lists. `oci://` URLs stay as the upstream gives them, and helm pulls those from
  the upstream registry.

## OCI charts

For a Helm OCI repository (format `helmoci`), this command runs `helm registry login`:

```bash
relic package setup helm helm-oci --write
```

To log in by hand, with your token as the password:

```bash
helm registry login relic.example.com --username <you>
```

Push a chart:

```bash
helm push web-1.4.0.tgz oci://relic.example.com/helm-oci
```

Install it:

```bash
helm install web oci://relic.example.com/helm-oci/web --version 1.4.0
```

A Helm repository also accepts OCI pushes, but its `index.yaml` lists only uploaded archives.
