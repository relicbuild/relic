---
title: Generic files
description: Any file, found by path, properties and search.
---

Generic repositories accept any file.

Upload a file:

```bash
relic artifact upload app.tar.gz generic-local/app/1.0/app.tar.gz
```

Download it:

```bash
relic artifact download generic-local/app/1.0/app.tar.gz
```

Set a property on a folder and everything under it:

```bash
relic artifact props set generic-local/app/1.0 release=1.0 --recursive
```

Search a repository:

```bash
relic artifact search app --repository generic-local
```

See [Artifacts](/docs/cli/files) for copy, move, delete and properties.
