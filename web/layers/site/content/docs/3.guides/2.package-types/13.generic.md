---
title: Generic files
description: Store any file in a generic repository, with properties and search.
---

Upload any file:

```bash
relic artifact upload app.tar.gz generic-local/app/1.0/app.tar.gz
```

Download it:

```bash
relic artifact download generic-local/app/1.0/app.tar.gz
```

Set a property on a folder and its contents:

```bash
relic artifact props set generic-local/app/1.0 release=1.0 --recursive
```

Search a repository by name:

```bash
relic artifact search app --repository generic-local
```

See [Artifacts](/docs/cli/files) for copy, move and delete.
