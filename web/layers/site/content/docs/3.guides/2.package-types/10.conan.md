---
title: Conan
description: Use a Conan repository as a Conan 2 remote for C and C++ packages.
---

This command adds the repository as the last remote, named after it, and logs you in:

```bash
relic package setup conan conan --write
```

Conan still asks `conancenter` first. Install from the repository only:

```bash
conan install . --remote conan
```

To add the remote by hand, before `conancenter`:

```bash
conan remote add relic https://relic.example.com/conan/conan --index 0
```
