---
title: Conan
description: Conan 2 remotes.
---

This command runs `conan remote add` and logs you in. It names the remote after the
repository (`conan` here) and adds it after `conancenter`:

```bash
relic package setup conan conan --write
```

Conan asks its remotes in order, so it still takes packages from `conancenter` first.
Install from the repository only:

```bash
conan install . --remote conan
```

To add the remote by hand, before `conancenter`:

```bash
conan remote add relic https://relic.example.com/conan/conan --index 0
```
