---
title: Relic API clients
description: Generate typed Go or TypeScript clients of the Relic API from its protobuf definitions.
---

The [Relic API](/docs/api/relic-api) is defined in protobuf under
`api/proto/relic/v1`. Relic serves it with [ConnectRPC](https://connectrpc.com).
Any Connect or gRPC-Web client generated from those files can call it. Native
gRPC clients cannot, because they need HTTP/2 and the server speaks HTTP/1.1.
The web UI and the [`relic` CLI](/docs/cli/overview) are Connect clients.

## Go

The Relic protos import `google/api/annotations.proto`, which the Relic
repository keeps in `third_party/proto`. Copy both `api/proto` and
`third_party/proto` into your project, or reference the Relic repository from a
buf workspace. A `buf.yaml` that lists both directories as modules:

```yaml
version: v2
modules:
  - path: api/proto
  - path: third_party/proto
```

Then generate the client with `protoc-gen-go` and `protoc-gen-connect-go`,
using a `buf.gen.yaml` like this one. It generates code for `api/proto` only;
the generated code imports the annotations from
`google.golang.org/genproto/googleapis/api`:

```yaml
# buf.gen.yaml
version: v2
managed:
  enabled: true
  disable:
    - path: google
  override:
    - file_option: go_package_prefix
      value: example.com/yourapp/gen
inputs:
  - directory: api/proto
plugins:
  - remote: buf.build/protocolbuffers/go
    out: gen
    opt: paths=source_relative
  - remote: buf.build/connectrpc/go
    out: gen
    opt: paths=source_relative
```

Call the API with the generated client and an access token:

```go
client := relicv1connect.NewRepositoryServiceClient(http.DefaultClient, "https://relic.example.com/api")
req := connect.NewRequest(&relicv1.ListRepositoriesRequest{})
req.Header().Set("Authorization", "Bearer "+token)
resp, err := client.ListRepositories(ctx, req)
```

The base URL ends in `/api`. Every method is at
`/api/relic.v1.<Service>/<Method>`.

Without a generated client, you can call the REST routes (`/api/v1/…`) with any
HTTP client. The [API reference](/api-reference) lists them.

## TypeScript

Generate the client with `protoc-gen-es`. The web UI generates its client into
`web/app/gen`. Call the API with `@connectrpc/connect`:

```ts
import { createClient } from '@connectrpc/connect'
import { createConnectTransport } from '@connectrpc/connect-node'
import { RepositoryService } from './gen/relic/v1/repository_pb'

const transport = createConnectTransport({
  baseUrl: 'https://relic.example.com/api',
  httpVersion: '1.1',
  interceptors: [next => req => { req.header.set('Authorization', `Bearer ${token}`); return next(req) }]
})
const repos = createClient(RepositoryService, transport)
const { repositories } = await repos.listRepositories({})
```

## Errors and access

Errors are Connect codes, such as `unauthenticated`, `permission_denied`,
`not_found` and `invalid_argument`. Each method declares who may call it. See
[Authentication and access](/docs/api/relic-api#authentication-and-access).

## File contents

Messages never carry file contents. To upload or download a file, use plain
HTTP at `/api/v1/files/<repo>/<path>`. See
[File contents](/docs/api/relic-api#file-contents).
