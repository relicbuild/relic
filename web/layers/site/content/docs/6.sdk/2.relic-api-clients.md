---
title: Relic API clients
description: Generate typed Go or TypeScript clients of the Relic API from its protobuf definitions.
---

The [Relic API](/docs/api/relic-api) is defined in protobuf under
`api/proto/relic/v1` and served with [ConnectRPC](https://connectrpc.com). Any
Connect or gRPC-Web client generated from those files can call it. gRPC clients
need HTTP/2, which the server offers only when it serves HTTPS itself.

## Go

The protos import `google/api/annotations.proto` from `third_party/proto` in
the Relic repository. Copy `api/proto` and `third_party/proto` into your
project and list both in `buf.yaml`:

```yaml
version: v2
modules:
  - path: api/proto
  - path: third_party/proto
```

Generate code for `api/proto` with `protoc-gen-go` and `protoc-gen-connect-go`.
The generated code imports the annotations from
`google.golang.org/genproto/googleapis/api`:

```yaml
# buf.gen.yaml
version: v2
managed:
  enabled: true
  disable:
    - path: google
  override:
    - file_option: go_package_prefix
      value: example.com/yourapp/gen
inputs:
  - directory: api/proto
plugins:
  - remote: buf.build/protocolbuffers/go
    out: gen
    opt: paths=source_relative
  - remote: buf.build/connectrpc/go
    out: gen
    opt: paths=source_relative
```

Call the API with an access token. The base URL ends in `/api`:

```go
client := relicv1connect.NewRepositoryServiceClient(http.DefaultClient, "https://relic.example.com/api")
req := connect.NewRequest(&relicv1.ListRepositoriesRequest{})
req.Header().Set("Authorization", "Bearer "+token)
resp, err := client.ListRepositories(ctx, req)
```

## TypeScript

Generate the client with `protoc-gen-es` and call it with `@connectrpc/connect`:

```ts
import { createClient } from '@connectrpc/connect'
import { createConnectTransport } from '@connectrpc/connect-node'
import { RepositoryService } from './gen/relic/v1/repository_pb'

const transport = createConnectTransport({
  baseUrl: 'https://relic.example.com/api',
  httpVersion: '1.1',
  interceptors: [next => req => { req.header.set('Authorization', `Bearer ${token}`); return next(req) }]
})
const repos = createClient(RepositoryService, transport)
const { repositories } = await repos.listRepositories({})
```

## Errors, access and files

Errors are Connect codes, and each method declares who may call it
([Authentication and access](/docs/api/relic-api#authentication-and-access)).
Messages never carry file contents: use plain HTTP at
`/api/v1/files/<repo>/<path>` ([File contents](/docs/api/relic-api#file-contents)).
Without a generated client, call the REST routes in the
[API reference](/api-reference).
