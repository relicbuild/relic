---
title: Overview
description: Program against Relic with a client generated from the Relic API.
---

You can generate [Relic API clients](/docs/sdk/relic-api-clients) for Go and
TypeScript from the protobuf definitions. The clients call the
[Relic API](/docs/api/relic-api) under `/api/` with typed messages for
repositories, files, users, permissions, builds and scans. The
[relic CLI](/docs/cli/overview) is built on the Go client.

Clients authenticate with a user and password, or with an
[access token](/docs/guides/security/tokens).
