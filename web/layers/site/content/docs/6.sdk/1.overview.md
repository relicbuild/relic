---
title: Overview
description: Program against Relic with a client generated from the Relic API's protobuf definitions.
---

Generate [Relic API clients](/docs/sdk/relic-api-clients) for Go and
TypeScript from the protobuf definitions. The [relic CLI](/docs/cli/overview)
is built on the Go client. Clients authenticate with a user and password, or an
[access token](/docs/guides/security/tokens).
